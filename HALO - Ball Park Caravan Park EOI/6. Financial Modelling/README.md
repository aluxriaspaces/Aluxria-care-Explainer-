# 6. Financial Modelling  🟡 After §1–3 land

**Purpose:** Convert site, market and lease facts into a defensible feasibility model
that answers the master question — does the opportunity justify the investment and a
long-term stewardship lease?

## Build
**Existing baseline (§7)**
- [ ] Approximate current annual turnover + site numbers

**Redevelopment scenarios**
- [ ] Cabin revenue · caravan/site revenue · floating-cabin revenue · event revenue
- [ ] Capex aligned to master plan scope (~$15–20M indicative — confirm)
- [ ] Opex, lease rent / revenue-share, staging cashflow
- [ ] Returns, sensitivity (occupancy, ADR, capex), break-even, payback vs lease term

## Discipline
- Every output is a **modelled estimate with stated assumptions** — never presented
  as a guaranteed return.
- Run **conservative / base / upside** cases.
- Tie the lease term required for viability back to the master question.

§7 (financial opportunity); draws on §2, §5, §4.
