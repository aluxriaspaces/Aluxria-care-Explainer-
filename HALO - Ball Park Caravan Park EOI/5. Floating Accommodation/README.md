# 5. Floating Accommodation  🟡 Potential unique angle

**Purpose:** Test whether Murray River frontage can support floating accommodation —
a genuine differentiator if it is approvable, a distraction if it is not. Establish
feasibility before it shapes any concept.

## Capture
- [ ] Who controls the **riverbank, moorings and water access**? (Crown / WaterNSW /
      MDBA / Council / NSW Maritime)
- [ ] Existing **boat ramp / jetty / marina** infrastructure
- [ ] **Water depth** behaviour — dry vs flood periods; navigability
- [ ] **Approvability**: can floating accommodation be approved, and by whom?
- [ ] **Precedents** nearby (e.g. Murray houseboats, other floating tourism)

## Reality check
The Murray is a regulated, shared border river with significant flood variation and
multiple authorities. Treat floating accommodation as a **pilot (3–5 cabins) to be
proven**, not a headline promise, until tenure and approval pathways are confirmed.
