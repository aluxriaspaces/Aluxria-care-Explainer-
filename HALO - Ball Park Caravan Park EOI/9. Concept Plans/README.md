# 9. Concept Plans  🟡 HALO differentiators

**Purpose:** Develop and pressure-test the concepts that would make this a flagship
destination — each held to feasibility (planning, flood, tenure, market) before it
earns a place in the submission.

## Concepts to test
- [ ] **Riverfront luxury precinct** — premium modular cabins
- [ ] **Floating accommodation precinct** — 3–5 pilot floating cabins *(gated on
      folder 5 feasibility)*
- [ ] **Event precinct** — weddings, conferences
- [ ] **Indigenous tourism** — cultural experiences, built through genuine partnership
      with Traditional Owners (not tokenistic; co-designed)
- [ ] **Wellness retreat** — riverfront wellness offer
- [ ] **Agritourism links** — Riverina food & wine experiences

## For each concept
- [ ] One-page rationale: market demand, fit, differentiation
- [ ] Constraints check (planning, flood, tenure, capex)
- [ ] Staging and dependency on other concepts
- [ ] Keep / park / discard
