# 3. Planning & Zoning  🔴 Priority (constraints can be deal-breakers)

**Purpose:** Define what can lawfully be built and operated. Flood is likely the
single biggest constraint on a Murray River park.

## Capture
- [ ] Current **zoning** + permitted uses (Federation LEP / planning portal)
- [ ] **Tourism accommodation** provisions
- [ ] Building **height limits** and **river setbacks**
- [ ] **Flood**: overlays, flood planning levels, historical flood records
- [ ] **Bushfire**: BAL requirements
- [ ] **Heritage**: Aboriginal cultural heritage, environmental/riparian protections

## Inputs
NSW Planning Portal (ePlanning), Federation LEP & DCP, council flood studies,
AHIMS search for Aboriginal heritage, Murray–Darling Basin / WaterNSW context.

## Maps to checklist
§3 (planning & zoning); informs §4 (river) and §10 (concepts).
