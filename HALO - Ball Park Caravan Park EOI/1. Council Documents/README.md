# 1. Council Documents  🔴 PRIORITY ONE

**Purpose:** Hold every primary document from Federation Council. These resolve the
largest share of lease, ownership, infrastructure and planning questions in one hit —
so this folder is the critical path.

## To obtain
- [ ] Official **EOI package** / tender documents
- [ ] **Information memorandum**
- [ ] **Site plans** (survey, lot/DP, services layout)
- [ ] Existing **lease / operator agreement** (if public)
- [ ] Council **reports and minutes** that resolved to run the EOI
- [ ] 2020 **master plan** document
- [ ] Contact for EOI queries (probity contact / procurement officer)

## How
- Federation Council EOI/tender portal or NSW eTendering (Tenderlink/VendorPanel).
- Direct request to Council's procurement / property team referencing the EOI.
- Lodge any clarification questions early via the official probity channel.
