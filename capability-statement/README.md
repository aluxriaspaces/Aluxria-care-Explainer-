# Aluxria — ICN Capability Statement

Capability statement for Aluxria, prepared for the Industry Capability Network (ICN).
A First Nations–led modular construction business delivering precision-built,
NCC-certified accommodation for renewable energy, resources, government
infrastructure and community housing across Australia.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Designed, print-ready capability statement (also the web page). Three A4 pages in the Aluxria brand system. |
| `Aluxria-ICN-Capability-Statement.pdf` | PDF export of `index.html` — the send/print-ready version. |
| `Aluxria-ICN-Capability-Statement.docx` | Editable Word master for updates and internal review. |

## Regenerating the PDF

The PDF is produced from `index.html` via headless Chromium (A4, backgrounds on).
Any local HTML-to-PDF workflow that honours the `@page` size and `print-color-adjust`
settings will reproduce it. Print from a browser with "Background graphics" enabled
and margins set to none / default for the same result.

## Items to confirm before external release

The document is grounded in Aluxria's published positioning. The following fields
are marked *"to confirm"* in the corporate-details panel and should be completed
before the statement is issued:

- ABN / ACN and registered office address
- Supply Nation registration number
- ICN Gateway registration
- Insurances (public liability, professional indemnity, workers compensation)
- Quality and other accreditations (e.g. ISO)
- Enquiry contact name, email and phone

Project statuses reflect Expressions of Interest and partnerships in development
as at 2026.
